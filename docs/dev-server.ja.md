# 開発サーバー（ブラウザで直す）

[English](dev-server.md) | 日本語

スライドの HTML を手で開かずに、ブラウザの上で文言・台本を直し、コメント（直してほしいこと）を残すための小さなサーバー。
選択肢・口・キーの一覧は [reference.ja.md#開発サーバー](reference.ja.md#開発サーバー)。
VS Code は要らない。待ち受けは 127.0.0.1 だけ。
Node を入れずに同じことをするなら[編集アプリ](editor.ja.md)（Chrome・Edge）。

## 起動

```bash
node server/dev.mjs examples/minimal/deck.html            # http://127.0.0.1:8730/
npm run dev -- path/to/deck.html --port 5174 --theme business
```

作業フォルダ（deck.html、narration.md、timeline.json、macros.tex、data/、figs/、components/、audio/manifest.json）と、
リポジトリの kit/、vendor/components/、themes/、自分のテーマのフォルダ（EGATARI_THEMES・~/.egatari/themes）を見張り（作業フォルダのうちシンボリックリンクのフォルダは見張らず、一度だけ知らせる）、変われば組み直して画面を読み込み直す（スライドとステップはそのまま）。
組み立てに失敗したときは、失敗の内容を画面に出す。直して保存すれば戻る。
`?presenter=1`、`?mode=lecture` などはそのまま使える。音声は `/deck/audio/…` から読む。

`/` のページはスライドを囲む外枠で、スライドそのものは sandbox の iframe（`/preview`）の中で動く。編集の道具（HTML の欄・台本の引き出し・コメントの欄と一覧）はスライドではなく外枠のページにある。スライドは「どこを直したいか」を知らせるだけで、HTML を読み・見せ・保存を押したときに書くのは外枠のページ（[守り](#守り)）。

## 操作

| 鍵 | すること |
|---|---|
| `e` | 編集モードの入り切り。直せる要素に枠が出る。**ダブルクリック**で HTML（要素の中身と `\( \)` の式）を外枠の横の板の欄に開き（スライドの上には重ねない）、⌘/Ctrl+Enter か「保存」で保存、Esc でキャンセル。HTML の欄・コメントの欄を開いている間、スライドはクリックを受けない |
| `n` | 台本の引き出し（右。スライドはその横に縮む）。今のステップの発言を直す（話者 Expert / Novice、発言の追加・削除・順番）。`{cue}` `{φ\|ファイ}` はそのまま書く。下に次のステップを表示 |
| `c` | コメントの一覧（未対応のもの。番号付き）。クリックでそのスライドとステップへ移り、スライドの上の点が光る。「解決」で対応済み |
| Alt+クリック（Mac は ⌥ option キーを押したままクリック） | その要素について コメントを残す。押した点（ピン）も残る：一覧を開いている間、画面のステップのコメントごとに、その場所へ番号付きの輪が出る（スライドの表示の大きさによらない） |
| `m`（編集モードの間、入力欄で打っていないとき。横の板の編集モードの帯の「マーカー（m）」のボタンと、編集中は「マーカー」になるスライドの操作の帯のペンのボタンでも。`d` でも開く） | マーカー：スライドに丸や矢印を描く。描き終えると、Alt+クリックと同じコメントの欄がその印について横の板に開く。欄が開いている間に描いた線も同じコメントの印になり（20 本まで。プレビューは描けるまま）、「残す」で全部の印をコメントと一緒に残し（`strokes`）、「キャンセル」で全部捨てる。印はスライドの上に（スライドの HTML の中ではなく）ピンと同じ色で描かれる。画面の端の表示は「編集中：マーカー」。もう一度 `m`（`d` でも）か Esc で切れ、編集モードを出ても切れる。入力欄で打っているときの `d`・`m` は字。編集モードでないときの `m` は何もせず、`d` は発表のペン。発表者ビューからはマーカーを選べず、編集中はその道具も断る |

鍵はスライドの上でも外枠の上でも効く。開いた欄や引き出しにフォーカスが移り、閉じるとスライドに戻る。

編集の道具（編集モードの帯・HTML の欄・コメントの欄と一覧・台本の引き出し）は、どれもスライドの隣の 1 つの板にあり、板の上には橙の帯 **編集中 — 開発サーバー** が付く。**スライドの場所に見えるものは、どれもスライドの HTML が描けるもの。信じてよいのは、この帯の付いた板の道具だけ。**
**編集モードと発表の道具は同時に使わない。** 編集モードに入ると、レーザーポインター・ペン・消えるペンを切り（書いた線は見えたまま残り、その上には描けない）、自動再生と音声を止め、スライド一覧・黒い画面・キーの一覧（?）・全画面・打ちかけのページ番号を閉じる。授業と字幕はそのまま。編集している間は、操作の帯の道具のボタン（自動再生・レーザーポインター・消えるペン・色・消す・一覧・全画面）を隠し、そのキー（`x` `v` Shift+`d` Backspace `o` `a` `b` `f`）は効かない。ペンのボタンだけは同じ絵のまま **マーカー** という名前で残り、そのボタンとペンのキー `d` は、ペンの代わりにマーカーを入り切りする（上の表）。発表者ビューで道具を選んでも切れる。編集モードを出ても、どれも元には戻さない。入力欄（HTML の欄やスライドの中の入力欄）で打ったキーは、いつも字として入り、道具やスライドの操作にはならない。今のモード（**編集中**・**発表の道具：ペン**・**表示**）はスライドの下の細い帯に出し（スライドには重ねない）、読み上げソフトにも知らせる。
矢印・Space・p・a・l などの発表の操作は、入力欄の外ではいつもどおり効く。`p` の発表者ビューは別の窓に開く（そこでもスライドは sandbox の中）。
スライドが読み込み直されても（保存のあと・外での変更のあと）入力は残るので、そのまま書き続けられる。その間に同じ要素やステップが変わっていれば、保存は断る。
保存した時点で HTML が別の所で変わっていたら（ハッシュが合わない）、保存せずに「スライドが変わっています。再読み込みしてください」と出す。
台本も同じで、引き出しを開いたあとにそのステップの行が別の所で変わっていたら、保存せずに「台本が変わっています」と出す（入力は残る）。

## 書き換えるファイル

- `deck.html`：ダブルクリックで直した要素の中身だけを置き換える
- `narration.md`：そのステップの行（`[k] …` とその続きの行）だけを置き換える。なければスライドの順・ステップの順の位置に足す。
  ほかの行（コメントを含む）は元のまま。発言を全部消すとそのステップの行を消す
- `comments.json`：コメント `[{id, created, key, range, pin, quote, comment, status}]`（key は `スライドの鍵:ステップ`、range は deck.html の位置、pin は押した点 `{x, y}` のスライドの座標（1280×720。表示の倍率によらない）。`pin` のない前のコメントもそのまま使える。マーカーは `strokes`（描いた印、同じ座標の点の並びの並び `[[[x, y], …], …]`。前のコメントは 1 本の `stroke` のこともあり、1 本の印として読む）を足し、その `pin` は全部の印の重心：[約束事 §13](contract.ja.md#13-レビューのメモ手書きの印)）。点はステップの最後の状態（`DECK.seek(i, k, Infinity)`）を指す（動いている途中に押しても）。quote は、点の近くに字があればそれ（図やパーツの中の札・語。60 字まで）から始まり、その後に要素の字の頭 80 字が続く
- `.cache/edits/`：書き換える前の deck.html・narration.md の写し（新しい 30 個）

## 守り

**スライドの HTML は書き込めない。** スライドの HTML の中のスクリプトやパーツは動くが、sandbox の iframe の中だけで動く。

- スライドの文書（`/preview`）は `<iframe sandbox="allow-scripts allow-modals">`（`allow-same-origin` なし）の中で開くので、origin を持たない。外枠のページ・その保存領域・合言葉を読めず、出せる要求はどれも `Origin: null` になる。
- スライドの文書には別の Content-Security-Policy を付ける：`connect-src 'none'`（`fetch`・XHR・beacon・イベントの流れを使えない）、画像・字・スタイルは `data:` / `blob:` だけ（組み立てが埋め込む）、音声は `/deck/audio/` だけ、iframe は決まった 1 つの口 `/preview` だけ（発表者ビューの中の画面）、フォームと `<base>` は使えない。決まりには `sandbox` も入れる。
- スライドの文書は外枠の iframe の中にだけ出す。外枠のページ（と発表者ビューの窓）は、そのページと一緒に作った印を付けて `/preview?cap=…` を読み込み、サーバーはブラウザが付ける `Sec-Fetch-Dest: iframe`（ページのスクリプトからは付けられない）も求める。タブで直接開いたとき（外枠の `frame-src` が効かず、移動の URL がデータを外へ運べる）は、印があっても `/preview` はスライドを出さず、何も動かない短い文字のページを返す（403、`Content-Security-Policy: sandbox; default-src 'none'`）。
- 作業フォルダのファイル（`/deck/…`）は文書として動かない：どの応答にも `Content-Security-Policy: sandbox; default-src 'none'` と `X-Content-Type-Options: nosniff` を付ける。音声・動画・画像・字は型のまま、それ以外（HTML・SVG・XML・スクリプト・テキスト）は `text/plain` か `application/octet-stream` にして `Content-Disposition: attachment` で返す。スライドの文書も外枠も、`/preview` のほかは iframe に入れられない。
- スライドの HTML が外枠に送るのは**知らせ**だけ：「この `data-src` の範囲と hash の要素を直したい」「この要素にコメントしたい」、鍵の `e`・`n`・`c`・Esc、今の位置。知らせは書き込む本文を持たない。外枠は知らせの形を確かめ、今の HTML を自分で読み、範囲と hash を確かめて、自分の欄や引き出しを見せる。書くのは、その欄や引き出しで「保存」（か ⌘/Ctrl+Enter）を押したときだけ。偽の本文を付けた知らせは無視する。知らせにできるのは、本当の HTML を見せる欄を開くことまで。コメントの知らせの点もほかと同じく確かめる：数だけ（ほかは点なし）、スライドの外は端に寄せ、0.1 に丸め、ほかの項目は捨て、近くの字は 60 字まで。サーバーでももう一度確かめる（`kit/core/comment-core.mjs`）。スライドの HTML は点を偽れるが、変わるのは印の位置だけ：コメントの本文は外枠で入力し、「残す」を押したときだけ書く。スライドの上の印は外枠が（クリックを受けずに）描き、場所は iframe の大きさから外枠が自分で求める。スライドの HTML は印の場所について何も知らせない。
- 合言葉は外枠のページにだけあり、スライドの文書には入れない。
- 編集の道具はスライドの場所の外、外枠の横の板（橙の印の帯付き）にだけ描く。スライドの HTML は自分の枠の外に描けない。信頼する欄で編集している間（HTML の欄・コメントの欄を開いている、台本の引き出しで入力している・未保存の変更がある）はスライドの iframe を `inert` にし、欄へのクリックや入力をスライドの HTML が横取りできないようにする。その間も外枠はスライドの位置を受け取るが、スライドの HTML からの知らせで板の欄を開け閉め・切り替えせず、編集している台本のステップも替えない。未保存の変更なしに台本の欄から離れれば、引き出しはまたスライドに付いていく。それでもスライドの HTML はスライドの場所に偽の欄を描ける（保存はできない）。信じるのは横の板だけ。

ほかのサイトを開いたブラウザからスライドや台本を書き換えられないように、次も断る。

- Host が `127.0.0.1:番号` か `localhost:番号` でない要求（DNS rebinding 対策）は 403
- `/__dev/` の口（書き込み・HTML の読み出し・コメント・`/__dev/info`・`/__dev/events`）は、起動のたびに作る合言葉が要る。
  合言葉は外枠のページ（`/`）にだけ埋め込み、外枠が `X-Deck-Token` で送る（`/__dev/events` は `?token=`）。
  合言葉が違えば 403（サーバーを起動し直したら画面を読み込み直す）
- `Origin: null`（sandbox のスライドが出す要求）や、`Sec-Fetch-Site` が `same-origin` でない要求は、合言葉が合っていても 403
- 書き込み（POST）は `Content-Type: application/json` でなければ 415、Origin が付いていて同じ番号の 127.0.0.1・localhost でなければ 403
- 文言の編集は、今の組み立てが直せると印を付けた要素（`data-src`）で、HTML の hash が変わっていないものだけ。台本の編集は、教材にあるスライドで、そのステップの今の版だけ。そうでなければ 409（か 400）
- 外枠のページはほかのページの iframe に入れられない（`frame-ancestors 'none'`）
- `/deck/…` はドットで始まる名前（`.cache/edits/` の写し、`.env` など）を出さない。symlink で作業フォルダの外を指すものも 403
- 壊れた URL（`/%ZZ` など）は 400
- 書き込みと控えは、シンボリックリンクを一切通らない：`deck.html`・`narration.md`・`comments.json`・`.cache`・`.cache/edits` のどれかがリンクなら（フォルダの中を指すもの・壊れたものも）、保存を 403 で断り、何も書かず何も消さない。書くときは同じフォルダの一時ファイルに書いてから rename で入れ替え、控えの掃除は控えの名前の普通のファイルだけを消す。`narration.md`・`comments.json` は実体が作業フォルダの中にあるときだけ、通常のファイルだけを、決まった上限（`deck.html` 32 MiB・`narration.md` 16 MiB・`comments.json` 4 MiB。開いたファイルの大きさで読む前に、読んだバイトでも確かめる）の内で読む（[format spec](https://github.com/egatari/egatari-spec) §11）。大きいファイルは読まずに 413、上限を超えるものになる保存は書かずに 413（控えも作らない）。`/deck/…` のファイルは `stat` で見た大きさまでだけ流す
- 台本の引き出しで「保存」を押した後、応答の前にまた入力すると、もう一度保存するまで未保存のまま（新しい入力は残り、引き出しはスライドに付いていかず、プレビューは inert のまま）

`tools/test-dev-server.mjs` は、書き込みを試みるスライド（`tools/hostile-deck.mjs`：古い書き込みの知らせを偽の本文で送り、合言葉を読み、外枠のページに触り、書き込みの口に合言葉なし・当て推量の合言葉で `fetch`・XHR・beacon するパーツとインラインのスクリプト）で、外枠で「保存」を押すまでフォルダの中が何も変わらないことを確かめる。

## AI のコーディング道具への頼み方

AI のコーディング道具（Claude Code・Codex・Gemini CLI など）に「comments.json のコメントを反映して」と頼む（Claude Code に motion-slides のスキルを入れていれば「コメントを反映して」で通じる）。道具は `comments.json` の `status: "open"` を読み、`key`・`quote`・`range` を手がかりに
deck.html（または narration.md・パーツ）を直し、終わったものを `"status": "resolved"` にする。
range はコメントを残した時点の位置なので、ずれていれば quote で探す。マーカー（`strokes`）は、描いた印がコメントの指すもの（丸の中・矢印の先）。`npm run comment-shots` が画像に印を描く。サーバーが動いていれば、直した結果はすぐ画面に出る。

コメントが何を指しているかを見るために、道具はまず次を動かすとよい。

```bash
npm run comment-shots -- <作業フォルダ>      # node tools/comment-shots.mjs <作業フォルダ> [id …] [--all]
```

スライドを組み、未対応のコメントごとにそのステップを画面なしのブラウザで描き（`DECK.seek(i, k, Infinity)`。毎回同じ絵になる）、点の印（マーカーなら描いた線を全部、同じ色で）を描いて `<教材>/.cache/comment-shots/`（git に入らない）に書く：`<id>.png`（点の周りのスライドの 480×300 を 2 倍で。線があれば、全部の線の外接矩形に 48 px の余白を足した範囲まで広げる。点がなければスライド全体）、`<id>-full.png`（スライド全体、1280×720）、`index.json`。プレビューからは画像を受け取らない。
