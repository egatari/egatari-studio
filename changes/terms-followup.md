### Changed

- Quality check, the build warnings and the fix request: the words that were kept with a narrower sense now follow the glossary too. A slide's key is 「スライドの id」 / “slide id” (for example 「スライドの id「…」が手書きの data-key で決まっている」); the `[0]` … `[concl]` at the start of a script line is 「ステップの指定」 / “step label”, with the valid ones listed on first use (「使えるステップの指定は [0] [1] [concl]」); 「アクセスの鍵」 → 「アクセスキー」; 原稿 meaning `deck.html` → 「スライド（deck.html）」; 「書き出し直す」 → 「元のアプリでエクスポートし直す」; 「TTS が読み」 → 「AI 音声が読み」 (“the AI voice reads it”), also in the stale-audio finding; the box around a figure label is 「ラベルの枠」 / “label frame”. The script parser's warnings say 「ステップ」 and 「ステップの指定」 instead of 「段階」, and the build refusals say 「パーツ」 and 「パーツライブラリ」 instead of 「部品」 and 「部品庫」. 秘密鍵, `data-mode="lecture"`, 古い形式の Office and the verb 「囲み」 (wrap the math in `\( … \)`) are kept
- AI instructions (the instruction pack in New…, `docs/authoring-with-llms*`, `docs/llm-parts/*`, the make and studio skills) and the fix, insert and outline requests use the same words as the findings: 段階 → ステップ, 段階の印 → ステップの指定 (English “step markers” → “step labels”), and コードの囲み → コードブロック, written 「灰色の枠（コードブロック）」 on first mention. The part notes that come from the parts library keep their own words (段階, 部品, 口述原稿) until components 2.7.0
- Glossary (`docs/terms.md`): two new rows, slide-id (スライドの id / Slide id) and step-label (ステップの指定 / Step label), which avoid 鍵, スライドの鍵 and ステップの鍵. The Japanese guides (`docs/reference.ja.md`, `docs/editor.ja.md`, `docs/distributing.ja.md`, `docs/contract.ja.md`) say 「スライドの id」 and 「スライドの id とステップ」 instead. New lessons start their script with 「# 台本:」 / “# Script:”. The terms lint also checks the AI instructions for 段階, 部品 and 口述原稿
- English guides (`docs/reference.md`, `docs/editor.md`, `docs/distributing.md`, `docs/contract.md`) say “slide id” (and “slide id and step”) instead of “slide key”, as the Japanese ones do; the spec's term is written “slide key (spec)”. The old anchor `#slide-keys` in the reference still works. The command-line messages of `render`, `npm run ids`, `tools/narration-json.mjs` and `egatari --help` / `egatari doctor` use the same words (ステップ, スライドの id, 台本, テンプレート, パーツ, Egatari ファイル, AI 音声), and the book's citation messages say 「引用キー」 / “citation key”
