### Added

- Quality check (`npm run check` and the editor app): figure geometry, the new standard R-geometry (backlog #201, `kit/core/geometry-check.mjs`). Parts that mark what they draw with `data-part` (boxes, edges with `data-part-line` lines, labels with `data-part-of`, points) are measured on each slide's final step, in slide coordinates: a line passing inside a box that is neither of its ends (`geoEdgeThroughBox`), a line crossing a label's text other than its own edge's label (`geoLineOverLabel`, info when the label has `data-part-halo`), two labels overlapping or a label over a point it does not belong to (`geoLabelOverlap`), and a box's label going past the box's border (`geoLabelOutsideBox`). All are warnings for now; each names the ids and rounded coordinates and gives one fix to make in the part's data. The text extent uses a fixed band above and below the baseline per font (`kit/core/text-band.mjs`, measured with `tools/measure-text-band.mjs`), and half the line width + 2px is tolerated. Marked labels are left to this check instead of `textOverlap` and `svgTextBox`. The command line and the editor run the same function and report the same findings (`tools/fixtures/check-parity/ja-geometry`)
- Vertical slides (`layout-tate`) are not measured yet: when every content slide of a lesson is vertical, R-geometry ends `skipped` with the new reason `tate`; a lesson that mixes both reports the number of marked vertical slides (`geoTateSlides`, info). A lesson without parts or marks excuses R-geometry (`noParts`). The quality check now accounts for 30 items, and the seeded-defect lesson has one more defect (30/30)
