### Changed

- Egatari Player 1.5.0 (the bundled player that files carry, `player` in the index and `deck-meta`): minor release. The presenter view's top-right pane is now **Next slide** (「次のスライド」): it shows the next slide in its final state, with all its steps, even while the current slide still has steps to go (with animation, the old pane showed only the next step). On the last slide it shows a plain “End” (「終わり」). The script pane still shows the next step's script under “Next step”
- Egatari Player 1.5.0: the presenter view's current pane always shows the slide's later steps faintly, like `l` and the preview (at the theme's `--preview-opacity`). This is the presenter's own view: the main window does not change. `l` and its button in the presenter view now turn showing later steps faintly on or off on the main window only, and the button shows the main window's state. No keys were added
