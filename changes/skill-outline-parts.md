### Changed
- `motion-slides` skill: the outline (構成案) gives each slide what to convey (伝えたいこと, from the parts library's purposes) and a recommended part, asked as a recommendation; interactive parts are marked “can be operated during the talk”, and tools (`m-timer`) are recommended only when the request mentions group work or time. The skill reads the full parts list (`vendor/components/CATALOG.md`, every part, standard and subject parts alike) and `manifest.json`; when no part fits, it may make a new expression from the components repository's expression catalogue and report it as a part candidate. One Egatari Studio clone is enough to use it (parts and themes are vendored); the components repository is needed only to propose parts.
