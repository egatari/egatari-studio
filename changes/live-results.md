### Added

- Live room results (draft, format extension `live` §3): **Import live room results…** in the Attachments panel and in **Distribute with a live room…** adds the results JSON downloaded from the room service as a `data` attachment (`attachments/live-<room>-<date>.json`, title with only the room and date). It is checked against the vendored egatari/live schema (now from 8e1e557), the 10 MiB limit and the §3.8 content checks; a room that differs from the lesson's live settings is warned about but allowed; the first import shows a one-time privacy notice. The list marks it "Learners' responses" with the number of questions and the tally per poll, shown as text only
- Results are never written into play-only copies. Exporting a single file that contains them warns and offers **Export without the results**; `npm run portable -- attach <dir> <results.json>` adds them from the command line, `pack` and `build --portable` print a warning, and `--without-live-results` leaves them out
