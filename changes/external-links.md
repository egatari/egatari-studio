### Security

- Links that leave the lesson (format spec §11): a click on a link to another site or file no longer navigates. The player shows the destination's host and full address and opens it only on **Open**, in a new tab with `noopener,noreferrer`; it asks every time when the link text names another host, the destination is not `https:`, the link downloads, the address has a user name or password, or the host is punycode, and once per host otherwise. `javascript:`, `data:`, `file:` and every scheme but `http(s)`, `mailto` and `tel` are refused. The box is keyboard-operable (focus on Cancel, Tab cycles, Esc cancels) and makes the lesson behind it inert. Middle and modified clicks are covered; video mode does nothing; the editor preview and dev server frame tell where the link goes but open nothing. The rule is a pure module, `kit/core/link-policy.mjs` (`DECK.LinkPolicy`), for the future play page
- SECURITY.md and the README: use a Node.js release with the latest security fixes (the 2026-10-21 releases fixed Brotli and TLS certificate checking issues)
