## 問の解答

:::{solution} exr-median
並べると 1, 3, 4, 8, 9 なので、中央値は 4。平均は $(1 + 3 + 4 + 8 + 9)/5 = 5$。

$c = 4$ のとき、ズレの絶対値の和は $3 + 1 + 0 + 4 + 5 = 13$。$c = 5$ のときは $4 + 2 + 1 + 3 + 4 = 14$。中央値の方が小さい。
:::

:::{solution} exr-even
$c = 4$ のとき $2 + 0 + 2 + 5 = 9$、$c = 5$ のとき $3 + 1 + 1 + 4 = 9$、$c = 6$ のとき $4 + 2 + 0 + 3 = 9$。

4 と 6 の間では左右に 2 個ずつあるので、傾きは 0 で和は 9 のまま変わらない。和が最小になるのは $4 \le c \le 6$ の範囲で、真ん中の 2 つの値の間になる。
:::

:::{solution} exr-square
平均は $(3 + 5 + 10)/3 = 6$。平均からのズレの二乗の和は $9 + 1 + 16 = 26$ なので

$$
\sum_{i=1}^{3} (x_i - c)^2 = 3\,(c - 6)^2 + 26
$$

最小値は $c = 6$ のときの 26。
:::

:::{solution} exr-ratio
割合は $90 / (60 + 90) = 0.6$。記録を小さい順に並べると、11 番目が 40、12 番目が 41、13 番目が 42 である。

$q = 41$ のとき、41 個より少ない日は 11 日（0.55）、41 個以下の日は 12 日（0.6）。$q = 42$ のとき、42 個より少ない日は 12 日（0.6）、42 個以下の日は 13 日（0.65）。どちらも 0.6 をはさむので、損が最小になるのは 41 個と 42 個（どちらでも同じ損）。
:::

## 用語

:::{glossary}
代表値
: データ全体を 1 つの値で代表させたもの。平均や中央値など。

平均
: 値を全部足して、値の個数で割ったもの。ズレの二乗の和を最も小さくする値。

中央値
: 値を小さい順に並べたとき、ちょうど真ん中に来る値。ズレの絶対値の和を最も小さくする値。

損失
: 選んだ値の悪さを数で表したもの。この本では、ズレの絶対値の和や二乗の和。

分散
: 平均からのズレの二乗を全部足して、個数で割ったもの。

外れ値
: ほかのデータから大きく離れた値。

分位点
: 値を小さい順に並べたとき、下からある割合の所にある値。中央値は 0.5 の分位点。

機会損失
: 得られたはずの利益を得られなかったことによる損。

臨界比
: 新聞売り子問題で、足りない損を、余る損と足りない損の和で割ったもの。最適な仕入れ数はこの割合の分位点になる。
:::
