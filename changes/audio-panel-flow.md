### Changed
- The Audio panel is redesigned in three parts. **A** (always on top) is one status line — how many steps have audio, how many need updating because the script changed, how many AI-made steps are still in the old voice after you changed the voice (compared through `recipe.voice`, since `inputHash` ignores the voice), and “Not in the file until you save” in a single file — with one action, **Make the rest (n steps)**, **Update audio (n steps)** or **Save**, that continues with the method used last (kept as `studio.audioMethod` in `egatari.json`). **B** asks “How do you want to add audio?”: make AI audio in the cloud (Google Colab, the default), on this computer (shown only with WebGPU, then the default) or record your own voice (recording mode); the voice fields sit above the answers and read “Voice of the explainer” / “Voice of the questioner” for a dialogue. **C** is this step: Play, Listen with read-aloud, Record (r), Import from a file…, Revert and Remake on this computer.
- The cloud path is three ticked steps: Export the script (the privacy question is asked once per browser), Open Colab (the steps — Connect, switch to CPU if a T4 cannot connect, Run all, choose the file, the ZIP downloads — are written in the panel and at the top of the Colab notebook, in Japanese and English) and Import the audio… (a plain file input; no folder picker).
- Removed from the Audio panel: the “when there is no WebGPU” framing, the export scope, the “marked” list of steps whose script changed after the export (they are offered as **Update audio** instead), “Regenerate with TTS” (now “Remake on this computer”), and the stale pre-processing list. Recording mode wording: step, script, “points where the animation follows the voice”, “Use and next”.
