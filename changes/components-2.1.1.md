### Changed

- Components 2.0 lessons now use egatari/components **v2.1.1** by default (`components2.lock.json`; 2.1.0 and 2.0.0 stay available). `m-orbit` 2.0.1: the person on Earth no longer spins a full turn on a step between two positions with the same observer angle (e.g. `start` 1 → `visit` [2] with 8 positions, both held at evening); a full turn is added only when the step passes position 0 (new moon). Every other part keeps the same version and the same `index.js` as 2.1.0. The parts library also fixed the `m-timer` and `m-tape` demo pages (the parts list's thumbnails) and relabelled a stale `CHANGELOG.md` line ("components 2.0, alpha; not for lessons yet" → "components 2.0.0-rc.1 and 2.0.0") carried by many 2.0.0-era parts; `tools/components2-update.mjs` now refreshes a part's vendored files when only this kind of ancillary text changes under an unchanged `index.js`, instead of silently keeping the first-ever copy forever (#142 follow-up).
