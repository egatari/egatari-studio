---
name: m-pipeline
summary: ロジットのノイズのモデル θ* → θ̂ = θ* + ε → p̂ = σ(θ̂) を、3 本の線の上の点の移動で見せる
steps: 3
props: span, left, dur
---

データは `data/pipeline.json`（`scripts/make_data.py`）：`{tau, theta_star, eps, range}`。

- 段階 1：真のロジット θ* の線に点が左から順に現れる
- 段階 2：点が観測されたロジット θ̂ の線へ落ち、ε だけ横にずれる
- 段階 3：点が予測 p̂ の線へ落ち、σ で 0 と 1 の端に寄る（色が紺から赤へ）

点は線の上に積み上げる（ドットプロット）。前の線には点を薄く残す。ロジットの線の範囲は `range` の `span` 倍
（θ̂ は range をはみ出すため）。積む高さが線の間隔を超えるときは詰める。高さは 300px 前後を想定。
