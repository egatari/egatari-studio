### Added

- Ink notes in edit mode (#70): `m` or the pen key `d` (or the "Ink note (m)" button in the editor's edit-mode bar, or the slide controls' pen button, which reads "Ink note" while editing and is the only tool button left there) turns the pointer into a comment pen; `d` typed into a text field stays text and the presenter view still cannot choose tools while editing. Drawing a circle or an arrow on the slide opens the same note box as Alt+click, and the preview stays drawable while the box is open, so further strokes (an arrow plus a circle, several underlines) join the same pending note; Leave keeps them all, Cancel discards them all. The marks are kept in `comments.json` as `strokes: [[[x, y], …], …]` in slide coordinates (at most 20 strokes, 500 points each, 2000 in all); `pin` is the length-weighted centroid over all strokes, set by the writers. An entry with a single `stroke` is read as `strokes: [stroke]`, and writers write only `strokes` (contract §13). The editor's overlay and `npm run comment-shots` draw every stroke in the pin colour, the crop covers all of them, and the mode indicator reads "Editing: ink note".
