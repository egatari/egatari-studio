# 開発サーバー（ブラウザで直す）

[English](dev-server.md) | 日本語

HTML の原稿を手で開かずに、ブラウザの上で文言・口述原稿を直し、Claude への指示を残すための小さなサーバー。
選択肢・口・キーの一覧は [reference.ja.md#開発サーバー](reference.ja.md#開発サーバー)。
VS Code は要らない。待ち受けは 127.0.0.1 だけ。
Node を入れずに同じことをするなら[編集アプリ](editor.ja.md)（Chrome・Edge）。

## 起動

```bash
node server/dev.mjs examples/minimal/deck.html            # http://127.0.0.1:8730/
npm run dev -- path/to/deck.html --port 5174 --theme tml
```

原稿のフォルダ（deck.html、narration.md、timeline.json、macros.tex、data/、figs/、components/、audio/manifest.json）と、
リポジトリの kit/、components/、themes/ を見張り、変われば組み直して画面を読み込み直す（スライドと段階はそのまま）。
組み立てに失敗したときは、失敗の内容を画面に出す。直して保存すれば戻る。
`?presenter=1`、`?mode=lecture` などはそのまま使える。音声は `/deck/audio/…` から読む。

`/` のページはデッキを囲む外枠で、デッキそのものは sandbox の iframe（`/preview`）の中で動く。編集の道具（原稿の欄・口述原稿の引き出し・コメントの欄と一覧）はデッキではなく外枠のページにある。デッキは「どこを直したいか」を知らせるだけで、原稿を読み・見せ・保存を押したときに書くのは外枠のページ（[守り](#守り)）。

## 操作

| 鍵 | すること |
|---|---|
| `e` | 編集モードの入り切り。直せる要素に枠が出る。**ダブルクリック**で原稿（HTML と `\( \)` の式）を外枠の横の板の欄に開き（スライドの上には重ねない）、⌘/Ctrl+Enter か「保存」で保存、Esc で取消。原稿の欄・指示の欄を開いている間、スライドはクリックを受けない |
| `n` | 口述原稿の引き出し（右。スライドはその横に縮む）。今の段階の発言を直す（話者 Expert / Novice、発言の追加・削除・順番）。`{cue}` `{φ\|ファイ}` はそのまま書く。下に次の段階を表示 |
| `c` | Claude への指示の一覧（未対応のもの）。クリックでそのスライドへ、「解決」で対応済み |
| Alt+クリック（Mac は ⌥ option キーを押したままクリック） | その要素について Claude への指示を残す |

鍵はスライドの上でも外枠の上でも効く。開いた欄や引き出しにフォーカスが移り、閉じるとスライドに戻る。

編集の道具（編集モードの帯・原稿の欄・指示の欄と一覧・口述原稿の引き出し）は、どれもスライドの隣の 1 つの板にあり、板の上には橙の帯 **編集中 — 開発サーバー** が付く。**スライドの場所に見えるものは、どれもデッキが描けるもの。信じてよいのは、この帯の付いた板の道具だけ。**
矢印・Space・p・a・l などの発表の操作は、入力欄の外ではいつもどおり効く。`p` の発表者ビューは別の窓に開く（そこでもデッキは sandbox の中）。
デッキが読み込み直されても（保存のあと・外での変更のあと）入力は残るので、そのまま書き続けられる。その間に同じ要素や段階が変わっていれば、保存は断る。
保存した時点で原稿が別の所で変わっていたら（ハッシュが合わない）、保存せずに「原稿が変わっています。再読み込みしてください」と出す。
口述原稿も同じで、引き出しを開いたあとにその段階の行が別の所で変わっていたら、保存せずに「口述原稿が変わっています」と出す（入力は残る）。

## 書き換えるファイル

- `deck.html`：ダブルクリックで直した要素の中身だけを置き換える
- `narration.md`：その段階の行（`[k] …` とその続きの行）だけを置き換える。なければスライドの順・段階の順の位置に足す。
  ほかの行（コメントを含む）は元のまま。発言を全部消すとその段階の行を消す
- `comments.json`：Claude への指示 `[{id, created, key, range, quote, comment, status}]`（key は `スライドの鍵:段階`、range は deck.html の位置）
- `.cache/edits/`：書き換える前の deck.html・narration.md の写し（新しい 30 個）

## 守り

**デッキは書き込めない。** デッキの中のスクリプトや部品は動くが、sandbox の iframe の中だけで動く。

- デッキの文書（`/preview`）は `<iframe sandbox="allow-scripts allow-modals">`（`allow-same-origin` なし）の中で開くので、origin を持たない。外枠のページ・その保存領域・合言葉を読めず、出せる要求はどれも `Origin: null` になる。
- デッキの文書には別の Content-Security-Policy を付ける：`connect-src 'none'`（`fetch`・XHR・beacon・イベントの流れを使えない）、画像・字・スタイルは `data:` / `blob:` だけ（組み立てが埋め込む）、音声は `/deck/audio/` だけ、iframe は決まった 1 つの口 `/preview` だけ（発表者ビューの中の画面）、フォームと `<base>` は使えない。決まりには `sandbox` も入れるので、タブで直接開いてもデッキの文書は origin を持たない。
- 原稿のフォルダのファイル（`/deck/…`）は文書として動かない：どの応答にも `Content-Security-Policy: sandbox; default-src 'none'` と `X-Content-Type-Options: nosniff` を付ける。音声・動画・画像・字は型のまま、それ以外（HTML・SVG・XML・スクリプト・テキスト）は `text/plain` か `application/octet-stream` にして `Content-Disposition: attachment` で返す。デッキも外枠も、`/preview` のほかは iframe に入れられない。
- デッキが外枠に送るのは**知らせ**だけ：「この `data-src` の範囲と hash の要素を直したい」「この要素にコメントしたい」、鍵の `e`・`n`・`c`・Esc、今の位置。知らせは書き込む本文を持たない。外枠は知らせの形を確かめ、今の原稿を自分で読み、範囲と hash を確かめて、自分の欄や引き出しを見せる。書くのは、その欄や引き出しで「保存」（か ⌘/Ctrl+Enter）を押したときだけ。偽の本文を付けた知らせは無視する。知らせにできるのは、本当の原稿を見せる欄を開くことまで。
- 合言葉は外枠のページにだけあり、デッキの文書には入れない。
- 編集の道具はスライドの場所の外、外枠の横の板（橙の印の帯付き）にだけ描く。デッキは自分の枠の外に描けない。原稿の欄・指示の欄を開いている間はデッキの iframe を `inert` にし、欄へのクリックや入力をデッキが横取りできないようにする。それでもデッキはスライドの場所に偽の欄を描ける（保存はできない）。信じるのは横の板だけ。

ほかのサイトを開いたブラウザから原稿を書き換えられないように、次も断る。

- Host が `127.0.0.1:番号` か `localhost:番号` でない要求（DNS rebinding 対策）は 403
- `/__dev/` の口（書き込み・原稿の読み出し・コメント・`/__dev/info`・`/__dev/events`）は、起動のたびに作る合言葉が要る。
  合言葉は外枠のページ（`/`）にだけ埋め込み、外枠が `X-Deck-Token` で送る（`/__dev/events` は `?token=`）。
  合言葉が違えば 403（サーバーを起動し直したら画面を読み込み直す）
- `Origin: null`（sandbox のデッキが出す要求）や、`Sec-Fetch-Site` が `same-origin` でない要求は、合言葉が合っていても 403
- 書き込み（POST）は `Content-Type: application/json` でなければ 415、Origin が付いていて同じ番号の 127.0.0.1・localhost でなければ 403
- 文言の編集は、今の組み立てが直せると印を付けた要素（`data-src`）で、原稿の hash が変わっていないものだけ。口述原稿の編集は、デッキにあるスライドで、その段階の今の版だけ。そうでなければ 409（か 400）
- 外枠のページはほかのページの iframe に入れられない（`frame-ancestors 'none'`）
- `/deck/…` はドットで始まる名前（`.cache/edits/` の写し、`.env` など）を出さない。symlink で原稿のフォルダの外を指すものも 403
- 壊れた URL（`/%ZZ` など）は 400

`tools/test-dev-server.mjs` は、書き込みを試みるデッキ（`tools/hostile-deck.mjs`：古い書き込みの知らせを偽の本文で送り、合言葉を読み、外枠のページに触り、書き込みの口に合言葉なし・当て推量の合言葉で `fetch`・XHR・beacon する部品とインラインのスクリプト）で、外枠で「保存」を押すまでフォルダの中が何も変わらないことを確かめる。

## Claude Code への頼み方

「コメントを反映して」と頼む。Claude Code は `comments.json` の `status: "open"` を読み、`key`・`quote`・`range` を手がかりに
deck.html（または narration.md・部品）を直し、終わったものを `"status": "resolved"` にする。
range は指示を残した時点の位置なので、ずれていれば quote で探す。サーバーが動いていれば、直した結果はすぐ画面に出る。
