### Changed

- Components 2.0 lessons now use egatari/components **v2.1.2** by default (`components2.lock.json`; 2.1.1, 2.1.0 and 2.0.0 stay available). Fixes from an audit of all 38 element parts: 37 parts get a new patch version (`m-kakijun` is unchanged). Code only — no README text, `doc` prop or static shape changed, so this release's AI instruction pack matches 2.1.1 except for version strings. Highlights: `m-hissan` 2.0.1 wrote wrong digits (or NaN) for products past 2^53 (e.g. 123456789×987654321 ended in "…260" instead of "…269"); products are now exact. `m-boxplot` 2.0.1 rounded quartiles against its own README's table (6.25 shown as 6.3); they are now exact. `m-kobun` 2.0.1 with `tate` drew 0 wide and opened its card off the slide, and showed 接頭/接尾 as 接; this is now reported and drawn correctly. Several parts' final (printed) state was missing information: `m-collect` 2.0.1 now keeps what was collected instead of fading every chip to opacity 0; `m-quad` 2.0.2 keeps where a moved point started; `m-codetree` 2.0.1 draws every decoded path in its summary; `m-kanbun` 2.0.1 keeps the arcs and order numbers; `m-menu` 2.0.1 prints each card's target slide; `m-keyboard` 2.0.2 keeps earlier steps' labels with `cumulative`. Every part except `m-kakijun` (which already had one) now has a role and an accessible name stating its final state, with the svg hidden from assistive technology and an author's `aria-label` kept. The parts list's `m-tape` and `m-score` demos also changed (tape's rows are now labelled A/B, not colour names; the rhythm slide steps `by="measure"` so eighth notes keep their length).
