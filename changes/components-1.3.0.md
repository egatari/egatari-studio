### Changed
- Components v1.3.0 is the default version (1.0.0–1.2.1 are kept for lessons that recorded them). `m-curves` gains the series words of `m-scatter`: `step` (series with the same `step` are drawn together), `tone`, `labelAt` (where the series name sits) and `anchor` `right` / `left` / `above` / `below`. The old forms still work and draw identically (`color`, `at` as the x of the name, `anchor` `start` / `middle` / `end`); they are described only outside the AI notes. The `m-scatter` notes no longer refer to `m-curves` for the axes. Instructions pack `5cc9551c` → `0f5e51c9`; free plan with all subjects: ja 59,825 B, en 58,528 B (cap 60,416 B). Release notes: [egatari/components v1.3.0](https://github.com/egatari/components/releases/tag/v1.3.0)
