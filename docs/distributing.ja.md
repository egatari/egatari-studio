# 学ぶ人に教材を配る

[English](distributing.md) | 日本語

教材は 1 つの HTML ファイルで配る：[1 ファイル（`.ega.html`）](reference.ja.md#1-ファイル--portable)か、学ぶ人にはふつうその再生専用の写し（`--play-only`。原稿を持たず、スライドと音声だけ）。**ダウンロードしてブラウザで開けば**、今のどのブラウザ（Chrome・Edge・Safari・Firefox）でもオフラインで再生できる。困りごとのほとんどは、ファイルを開かずにプレビューだけを見せる場所から起きる。

| 配り方 | 学ぶ人に伝えること | 気をつけること |
|---|---|---|
| Google ドライブ（ドライブで共有する Google Classroom も） | 「ファイルをダウンロードしてから、ブラウザで開いてください」 | ドライブのプレビューは HTML を文字で見せるか何も見せず、教材は動かない。要る人に共有する（または「リンクを知っている全員」） |
| メール | 「添付を保存してから、ブラウザで開いてください」 | メールの大きさの上限（20〜25 MB のことが多い。音声が入ると大きくなる）。学校のメールの検査が `.html` の添付を止めたり外したりすることがある。そのときは `.zip` にするか、ドライブのリンクで送る |
| LMS（Moodle・Canvas・Classroom など） | 「ダウンロードしてから開いてください」 | ファイルの資料として載せ、選べるなら表示を「ダウンロード」にする。LMS のページの中で表示すると、スクリプトが止められて再生できないことがある |
| 自分のウェブの場所（学校のウェブサーバー・GitHub Pages など） | URL | そのまま開ける。スマートフォンやタブレットでも。静的なファイルを置ける所ならどこでもよく、サーバーでは何も動かない |

- **スマートフォン・タブレット：** ファイルのアプリの簡易表示（iPhone の「ファイル」App など）では動かないことがある。ブラウザで開くか、URL を渡す。すべての機械と経路はまだ確かめていない。動いた・動かなかった経路を教えてほしい（[感想を送る](https://github.com/egatari/egatari-studio/issues/new?template=feedback.yml)）
- **授業の前に確かめる：** 配るファイルを、自分のでない計算機で、学ぶ人と同じやり方（ダウンロードしてから開く）で開き、音声付きで 1 枚再生してみる
- **直せるファイルは手元に：** 配るのは再生専用の写しにし、あとで直すための 1 ファイルか作業フォルダは手元に残す（再生専用の写しは直せない）
- **WebGPU のない PC での音声：** WebGPU のない PC でも、エディタから Colab で音声を作れる（[Colab で音声を作る](editor.ja.md#colab-で音声を作るwebgpu-がないとき)）。<!-- colab-verified --> 確認済み：2026-10-21、Irodori、Colab の T4 GPU（作者の環境で 1 回）。Kokoro と CPU はまだ。**プライバシー：** Colab では原稿の文が Google の環境で処理されるので、共有してよい文だけに使う。書き出す `tts-job.json` には読み上げる文と声の名前だけが入り、教材のほかのものは入らない

## 授業の部屋（授業中の質問と投票。下書き）

再生専用の写しに **授業の部屋**（[形式の拡張 `live`](https://github.com/egatari/egatari-spec/blob/main/extensions/live.md)。下書き）を付けられる。決めた時間の窓のあいだ、ファイルを開いた学ぶ人が、アプリもアカウントもなしに、教材の中から質問を送り、投票に答えられる。教材の中でネットワークを使うのはここだけで、学ぶ人が **参加する** を押した後だけ。

1. 部屋のサービス（既定は `https://live.egatari.org`。サービスと通信の約束は [egatari/live](https://github.com/egatari/live)）の教員のページで **部屋を作る**。時間の窓を決める。一度だけ出る教員のリンクをブックマークする（教員の鍵が入っている。なくしたら作り直す）
2. 編集アプリで **書き出す ▾ →「授業の部屋を付けて配る…」**。教員のページの **コピー** の字（部屋・参加の鍵・時間の窓）を貼る。Q&A を教材全体で入／切し、段階ごとに投票（問いと 2〜6 の選択肢）を足す（**プレビューの段階** で画面の段階を入れられる）。投票には、教材のどこかを言う表示名が付く（例「4 枚目『XML の壁』・段階 1」。スライドの番号、約 24 字で切ったスライドの見出し、段階の番号。番号は 1 から）。表示名は段階の候補と投票の一覧に出て、段階の鍵（例 `s-cjatth:0`）は吹き出しに残る。段階を変えると表示名も変わる。表示名ができる前に残した投票は、板を開いたときにスライドがまだあれば付き、なければ鍵から「s-cjatth · 段階 1」の形で出る
3. **活動の JSON をコピー** し、教員のページの **活動** に貼る（部屋が同じ投票を知るため。知らない活動や選択肢への投票は部屋が断る）。JSON には表示名（`label`。表示のための字で、鍵は変わらない）が入るので、教員のページと参加用のページは段階の鍵の代わりに「4 枚目『XML の壁』・段階 1」を出し、結果の JSON にも残る。表示名のない部屋では、投票を段階の鍵で出す（「s-cjatth · 段階 1」。`*` は「教材全体」）
4. **部屋を付けて書き出す…** で再生専用の写しを書く。配り方はいつもと同じ（ダウンロードしてからブラウザで開く）

学ぶ人の写しのふるまい：

- **ネットワークに出ない：** 部屋がない・時間の窓の外（両端に 2 分のゆとり）・ブラウザで直接開いていない（ファイルかウェブのアドレスから）ときは何もしない。編集アプリのプレビュー、ほかのページの中（LMS・埋め込み）、動画（`?mode=video`）、印刷、発表者ビューではつながない。編集アプリのプレビューでは、代わりに部屋の場所を字で見せる。ほかのページの中や、つなげない形で見せているとき（チャットのアプリやファイルのアプリの表示、ほかの種類のアドレス）は、**ブラウザで参加する** を出す。部屋の参加用のページ（`https://<サービス>/join#room=…&key=…`。鍵は `#` の後ろだけ）を新しいタブで開くリンクで、押すまで何も読み込まない
- **ファイルからつながる端末：** パソコンのブラウザ（Chrome・Edge・Firefox・Safari）でダウンロードしたファイルを開けばつながる。Android では、ファイルのアプリからダウンロードしたファイルを Chrome で開いたとき（`content://` のアドレス）もつながる。学ぶ人が自分で開いたファイルとして扱い、条件は同じ（枠の中でない・時間の窓の中・写しの決まり・**参加する** を 1 回押す）。iPhone と iPad では、ダウンロードした HTML のファイルをブラウザで動かせない（ファイルのアプリはスクリプトなしで見せるだけ）ので、教員のページの **参加用のリンク** を使う。参加用のリンクはどの端末でも使える。Slack などのチャットのアプリは、大きな写し（音声入り）をプレビューできないことがあるので、ダウンロードしてもらう
- **参加の前に 1 回押す：** 教材は右上の小さな **ライブ** の印だけで始まる。印を押すと板が開き、教材がつながる先を見せて **参加する** を出す。つながっている間は、板をたたんでいても印そのものがずっと見える印になる（緑の点と、読み上げ用の状態の字）。**切断する** は開いた板にある。押したことはそのタブのあいだだけ覚える（新しいタブではまた聞く）
- **送るのは：** 学ぶ人が送ると決めた質問と投票、入れたときだけ名前、端末で作った乱数の番号（ブラウザの記憶に置く。使えなければメモリだけ）、つながりを保つ ping。見ている位置や時間は送らない。教材全体の Q&A では、送るを押したときに画面にある段階の鍵を、その質問に付ける
- **要るときだけ開く：** 板をたたんでいる間、スライドは窓いっぱいに出る。投票のある段階では板が自分で開き（読み上げで知らせ、フォーカスは動かさない）、その段階を離れるとまたたたむ。**開いたままにする**（ピン）を押したときと、印から自分で開いたときはたたまない。教材全体の質問は、どのスライドでも印を押せば質問の欄が開く。**×** か Esc でたたむ
- **舞台の外：** 開いた板は右（縦長の画面では下）に出し、スライドは残りの場所に収める。板がスライドを隠すことはない（そのかわり、開いている間スライドは小さくなる）。スライド・字幕・印・動画のコマ・印刷は変わらない。投票はその段階に来たときに出る。サーバーから来た字はすべて文字として出す
- **つなぎ直し：** 時間の窓の中でだけ、部屋のサービスの表のとおりにつなぎ直す。通信が切れたときは間をあけて（1・2・4 … 30 秒、±20%）、先生が部屋を閉じた（4423）ときはゆっくり（30 秒より後）、満員（4430）・送りすぎ（4429）の後は 60 秒より後、まだ早い（4425）ときは開く時刻に。鍵が替わった（4440）、時間が終わった・部屋がない（4410・4404）、鍵が違う（4403）、同じ人がほかで参加した（4409）、先生が参加を認めなかった（4441。**もう一度試す** を出す）ときは、わけを見せて止まり、自分からはつなぎ直さない。先生の承認を待つ部屋では、承認されるまで「待っています」と出す
- **部屋の大きさ：** 部屋のサービスの部屋は、同時に 60 人まで、時間の窓は 3 時間まで。編集アプリは 3 時間より長い窓を断る
- **つなぐ先を絞る：** 写しには CSP（コンテンツ セキュリティ ポリシー）を入れ、`connect-src` は部屋のサービス（そのホストの `https://` と `wss://`）だけ。再生器も、WebSocket の行き先が宣言した origin か確かめる。サービスからは何も（スクリプト・スタイル・画像）読み込まない

教材そのものには鍵のない設定だけを残す（`egatari.json` と 1 ファイルの索引の `extensions.live`）。参加の鍵は書き出した写しにだけ入る。写しを持っていれば、部屋が開いている間は誰でも参加できる。写しが広がったときは、教員のページで鍵を替えると古い写しは入れなくなる（わけを見せる）。コマンドでは `node kit/build.mjs <デッキ> --play-only --live room.json`（`room.json` は教員のページの「コピー」の字。投票は `egatari.json` の `extensions.live`、なければ `room.json` から）。

**授業の前に通しで確かめる：** 窓が今から始まる部屋を作り、書き出し、2 台で写しを開いて参加し、質問と投票を送って、教員のページに出ることを確かめる。配るときは、スマートフォンとタブレットのために参加用のリンクも添える。教員のページの **配るときの文** に、そのまま貼れる文がある。
