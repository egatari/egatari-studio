### Security

- Dependency updates from Dependabot: **KaTeX 0.18.2 to 0.19.0** (exact pin; its `commander` goes from 8.3.0 to 15.0.0, which needs Node 22.12 or later). All 109 formulas in the examples, fixtures and docs render to the same HTML and MathML byte for byte, and the font files are unchanged; `katex.min.css` adds `math` to the font fallbacks and a `.reflectbox` rule. **@fontsource/source-sans-3 5.3.0 to 5.3.1**. Dev only: **ajv 8.17.1 to 8.20.0** (ReDoS with `$data`, GHSA-2g4f-4pwh-qvx6) and **fast-uri 3.1.8 to 3.1.9** (four advisories); `npm audit` now finds nothing, with or without dev dependencies
- Node floor: `engines` is `^22.23.4 || ^24.22.1 || >=26.12.1` (the 2026-10-20/21 security release), and CI asks for `>=22.23.4 <23` and `>=24.22.1 <25` instead of `22` and `24`, which took the runner's cached 22.23.3 and 24.21.0 (SECURITY.md)
- Supply chain: CI and the release asset (`tools/site-versions.mjs`) install with `npm ci --ignore-scripts` (the only install script, esbuild's `postinstall`, is not needed); Dependabot waits 7 days (14 for a major version) before proposing a release (`cooldown`); the Pages workflow uses `actions/upload-pages-artifact` v5 and `actions/deploy-pages` v5. SECURITY.md and the threat model say how, and the Colab exception (`onnxruntime-node`'s `postinstall`)
