# プライバシー

[English](privacy.md) | 日本語

## このページについて

このページでは、Egatari を作っている私たち（Egatari の開発者）が、Egatari Studio（教材を作るアプリ。https://studio.egatari.org/）と、教材を再生するプレーヤー（Egatari Player）が、インターネットに何を送り、端末に何を残すかを説明します。

- 対象は、Studio、Studio が書き出す `.ega.html`（学習者に配るファイル）、再生専用のページ Egatari Viewer（https://viewer.egatari.org/）です。
- 書いてあるのは、プログラムの実際の動きです。広告や利用状況の計測は入れていません。
- 学校の IT 担当の方が通信を止めたり確かめたりできるように、止め方も書きます。
- 「ライブ」は、授業や発表の最中に、参加者が自分の端末から質問を送ったり投票したりできる機能です。時間を決めて開き、使うかどうかは作成者が教材ごとに選びます。ライブを付けていない教材は、ライブのサーバーにつながりません。
- コードの中の根拠（ファイルと行）は、英語版の[付録](privacy.md#appendix-evidence-in-the-code-for-maintainers)にあります。

## 教材のファイルはどこにあるか

- 教材は、あなたの PC のフォルダか、1 つのファイル（`.ega.html`）の中にあります。Studio は教材をサーバーに送りません。
- Studio のページは、外のサーバーにつなぐことを禁じる設定（CSP の `connect-src 'self'`）で動きます。つながる先は Studio のサイト自身だけです。
- 編集中の控えは、あなたが選んだフォルダの中の `.cache/edits/` に保存します。上限は 30 個です。
- Google Colab を使うときだけ、台本の文をあなたが自分で書き出し、自分で Colab に渡します（下の表）。

## インターネットに送るもの

表の「自動」は、ボタンを押さなくても起きる通信です。「操作」は、あなたがボタンを押したときだけ起きる通信です。

| 場面 | 送り先 | 送るもの | 止め方 |
|---|---|---|---|
| Studio のページを開く（自動） | studio.egatari.org（GitHub Pages で配信）。画面を動かすプログラム、字体、版の一覧（`versions.json`）を同じサイトから読み込む | ふつうのウェブページを開くときと同じもの（IP アドレス、ブラウザの種類など）。サイトを置いている GitHub と Cloudflare の記録は、下の「サイトの記録」のとおり | オフライン版のエディタ（`editor.html` を保存して開く）では、版の一覧を読み込まない |
| AI 音声を「この PC」で作る（操作。初回は確認の画面が出る） | モデルとライブラリの配信元：cdn.jsdelivr.net、huggingface.co、us.aws.cdn.hf.co（Hugging Face の配信用）。この通信は Studio とは別の小さな窓で行う。読み込むプログラムは版を固定し、中身が変わっていないことを確かめてから動かす（v0.6.6 から） | ファイルを取りに行く要求だけ。台本の文や教材の中身は送らない。音声はあなたの PC の GPU で作る | 確認の画面で取り消す。使わなければ何も読み込まない。モデルは「使い方」にある「モデルを消す」で消せる |
| AI 音声を Google Colab で作る（操作。初回は確認の画面が出る） | あなたが書き出した `tts-job.json` を、あなたが Colab の画面で選ぶ。Colab は Google のサービス | `tts-job.json` の中身：台本の文（読みの辞書を通したもの）、声の名前、教材の題（120 字まで）、教材の ID、版。スライドやほかのファイルは入らない。声をまねるために自分の参照音声を選んだ場合は、それも Colab に渡す | 「クラウドで作る」を使わず、録音か「この PC」を選ぶ |
| Colab の中（Colab が自動で行う） | GitHub（Studio のプログラム）、PyPI と npm（ライブラリ）、Hugging Face と GitHub のリリース（モデル） | ファイルを取りに行く要求だけ。Google のサーバーの中で起きる通信 | 同上 |
| 「フィードバックを送る」を押す（操作） | github.com/egatari/egatari-studio/issues/new（新しい窓で開く。フォームは、あなたが送信するまで送られない） | フォームに最初から入っている欄：版、ブラウザの名前と主な版番号、OS の種類、言語、モード。教材の中身は入らない | ボタンを押さない。`.ega.html` を書き出すときに `data-feedback="off"` を付けると、ボタン自体が出ない |
| 手引きやパーツの見本などのリンクを押す（操作） | github.com、studio.egatari.org、ライブのホストのページなど | ふつうのリンクを開くときと同じ（行き先のサーバーが受け取るもの） | リンクを押さない |
| ライブ（質問・投票）を使う（参加者が「参加する」を 1 回押す） | 教材に書いてあるライブのサーバー（既定は https://live.egatari.org。作成者が別のサーバーを指定できる） | 参加者が送ると決めた質問と投票、入力したときだけ名前、端末で作った乱数の ID、接続を保つための ping、参加コード（v0.6.6 から、接続のアドレスには入れず、つないだ後の最初のやりとりで送る）。見ている位置や時間は送らない | ライブを付けずに書き出す。学校のネットワークで、そのサーバーだけを止める |

補足：
- アクセス解析：Studio にもプレーヤーにも、アクセス解析のプログラムは入れていません。サイトを置いている GitHub と Cloudflare が残すアクセスの記録は、下の「サイトの記録」のとおりです。
- 外のサーバーからスクリプトを読み込むのは、音声のモデルを取る窓だけです（版と中身を固定しています）。Studio 本体のページは、外のスクリプトを読み込みません。

## 送らないもの

Studio とプレーヤーは、次のものを送りません。

- 教材のスライド・台本・音声・画像を Studio のサーバーへ送ることはありません。教材を保存したり共有したりする仕組みが、サーバーにありません。
- Studio のプレビューは、外へつながない設定（`connect-src 'none'`）で動きます。
- 読み上げ（ブラウザの音声）には、端末に入っている声だけを使います。ネットワーク上の声は選びません。
- 録音は端末の中で処理します。マイクを使うのは、録音のボタンを押したときだけです。
- `.ega.html` は、ライブを付けていなければ、インターネットに何も送りません（下の節）。
- 学習者がどこを見たかや進み具合を、Egatari のサーバーへ送ることはありません。LMS の中で開いたときと、ほかのページに埋め込んだときだけ、そのページに渡します（下の節）。

## この端末に残すもの

どれもブラウザの中だけに残り、外へは出ません。ブラウザのサイトデータを消すと、なくなります。

| 場所 | 名前（キー） | 中身 | 消し方 |
|---|---|---|---|
| localStorage（Studio） | `motion-editor-lang` | 選んだ言語（ja / en） | サイトデータを消す |
| localStorage（Studio） | `egatari-colab-privacy-ok` | 「台本を Google に渡すことの確認」を済ませた印 | 同上 |
| localStorage（Studio） | `egatari-rec-keep-recording` | 録音の設定（1 つのオンとオフ） | 同上 |
| localStorage（Studio） | `egatari-slides-open` | スライド一覧を開いていたか | 同上 |
| localStorage（Studio） | `egatari-studio-live-results-notice` | ライブの結果を取り込む説明を見せた印 | 同上 |
| sessionStorage（Studio） | `motion-editor-reopen` | 言語を切り替えた直後に、教材を開き直すための印（タブを閉じると消える） | タブを閉じる |
| IndexedDB（Studio） | `motion-slides-editor` | 最近開いた教材のフォルダやファイルの「ハンドル」（場所を指す目印。最大 8 件）。教材の中身は残さない | サイトデータを消す |
| IndexedDB（Studio） | `egatari-theme-folder` | テーマのフォルダのハンドル。「自分のテーマ」（`my:<名前>`）は、テーマのファイルの中身ごと残す | 「自分のテーマ」の窓の「削除」、またはサイトデータを消す |
| Cache Storage（Studio の AI 音声の窓） | `irodori-lab-<版>`、`transformers-cache` | AI 音声のモデル（日本語は約 1.3 GB、英語は約 330 MB） | 「使い方」にある「モデルを消す」 |
| あなたのフォルダの中 | `.cache/edits/` | 編集する前の控え（上限 30 個） | フォルダから消す |
| localStorage（`.ega.html` のプレーヤー） | `deck-capsize` | 字幕の大きさ（S / M / L） | サイトデータを消す |
| localStorage（`.ega.html` のプレーヤー） | `<形式名>-player-bar-hint-v1` | 操作の案内を見せた印 | 同上 |
| localStorage（`.ega.html` のプレーヤー） | `<形式名>-player-progress:<教材>` | 教材ごとの進み具合（どのステップを再生したか、読んだか、最後まで終えたか） | 同上 |
| localStorage（`.ega.html` のプレーヤー） | `<形式名>-player-resume:<教材>` | 「前回の続きから」開くための、教材ごとの読んでいた所（スライド、ステップ、本の窓の中の位置） | 同上 |
| localStorage（`.ega.html` のプレーヤー） | `<形式名>-player-layout:<教材>`、`<形式名>-player-split`、`<形式名>-player-read-size`・`-read-lh`・`-read-bg` | 選んだ並べ方、仕切りの位置、本の窓の文字の大きさ・行間・背景 | 同上 |
| localStorage / sessionStorage（ライブのある `.ega.html`） | `egatari-live-pid:<ライブ ID>`、`egatari-live-joined:<ライブ ID>` | 端末で作った乱数の ID と、参加したかの印（参加の印はタブを開いている間だけ） | サイトデータを消す、タブを閉じる |
| Egatari Viewer：OPFS（使えなければ IndexedDB） | `recent/`、DB `egatari-viewer` | 最近開いた教材ファイルの写し（最大 10 件。この端末だけ） | 一覧の「削除」か「すべて消す」、または「共有の端末」にチェックを入れる |
| Egatari Viewer：localStorage | `egatari-viewer-keep`、`egatari-viewer-shared`、`egatari-viewer-lang`、`egatari-viewer-install-hint` | 写しを残すか、共有の端末か、言語、インストールの案内を閉じたか | サイトデータを消す |
| Egatari Viewer：Cache Storage | `egatari-viewer-<版>` | Viewer 自身のファイル（オフラインでも開けるようにするため）。教材ファイルは入れない | サイトデータを消す |

補足：
- 再生中は、アドレスの `#` の後ろが、今見ている所（スライドの ID とステップ）に書き替わります。また「前回の続きから」開けるように、教材ごとに読んでいた所をこの端末に残します（上の表）。埋め込んだとき、LMS の中、Studio のプレビューでは残しません。
- Egatari Viewer は、初めの設定のままだと、最近開いた教材の写しを残します。「共有の端末」にチェックを入れると写しを残さず、すでにある写しも消します。学校で共用する端末では、チェックを入れるよう案内してください。

## 学習者に配ったファイル（プレーヤー）

- 書き出した `.ega.html` には、外へつなぐことを禁じる設定（CSP の `connect-src 'none'`）が入っています。画像・音・字体には、ファイルの中に入れたものだけを使います。
- 外へ接続できるのは、ライブを付けたファイルだけで、接続先もそのライブのサーバーだけです。条件は次のとおりです。
  - ライブの時間の中であること。
  - ファイルを直接開いていること（LMS や別のページの枠の中では接続しません。枠の中では「ブラウザで参加する」のリンクが出るだけです）。
  - 参加者が「参加する」を 1 回押すこと。
- ? のキーの一覧と発表者ビューにある「フィードバックを送る」は、押したときだけ、GitHub を新しい窓で開きます。
- 教材の中の外へのリンクは、行き先を見せて確かめてから開きます。作成者が「埋め込み」（YouTube、Vimeo、Google Maps、OpenStreetMap）を入れた教材では、その行き先を表示してよい設定になり、教材を開いたときにその行き先から読み込まれることがあります。
- 進み具合の記録：LMS の中（SCORM 1.2）で開いたときは、進み具合（始めた・終えた、読んでいた所、どのステップを見たか、学習した時間）をその LMS に渡します。ほかのページに埋め込んだとき（`?embed=1`）は、同じ出来事を埋め込んだページに知らせます。どちらでもないときは、この端末に残すだけです（上の表）。

## 学校で使うときの確かめ方

CSP（通信を許す相手の設定）で確かめる方法：

1. `.ega.html` をテキストエディタで開きます。`<head>` の最初のほうに、`Content-Security-Policy` の `<meta>` が 1 つあります。
2. その中の `connect-src` が `'none'` なら、そのファイルは外へつながりません。ライブ付きのファイルなら、つながるのは `connect-src` に書かれた 1 つのサーバー（`https://…` と `wss://…`）だけです。
3. `frame-src` に YouTube などが足されていれば、その教材は埋め込みを使っています。
4. Studio（studio.egatari.org）のページの設定は、`default-src 'self'`、`connect-src 'self'`、`frame-src 'none'` です。AI 音声の窓（`lab/tts-helper.html`）だけが、`cdn.jsdelivr.net`、`huggingface.co`、`us.aws.cdn.hf.co` につながります。
5. Egatari Viewer は、通信を許す相手を HTTP ヘッダー（`_headers`）で指定しています。つながるのは Viewer 自身と、ライブのサーバー（既定は live.egatari.org）だけです。

通信を止めたい場合：

- 学校のフィルタで、`cdn.jsdelivr.net`、`huggingface.co`、`us.aws.cdn.hf.co`、`colab.research.google.com`、`live.egatari.org` を止めてください。止めても、編集・保存・再生はできます。使えなくなるのは「AI 音声をこの PC で作る」、Colab、ライブだけです。
- 通信なしで使うなら、`editor.html`（オフライン版のエディタ。1 つの HTML ファイル）を配ってください。AI 音声の「この PC」は使えませんが、録音と、前もって作った音声は使えます。
- 作った音声と、書き出した `.ega.html` は、通信なしで動きます（ライブを付けていない場合）。

## サイトの記録

サイトを置いている GitHub と Cloudflare は、ふつうのウェブサイトと同じように、アクセスの記録（IP アドレス、ブラウザの種類、開いたページなど）を残します。私たちはその記録を分析や広告に使わず、アクセス解析の仕組みも入れていません。

ライブのサーバー（live.egatari.org）は、ライブの中身（質問・投票・「わからない」の印、入力したときだけ名前、端末で作った乱数の ID）を、そのライブの中だけに置きます。ライブの時間が終わってから猶予の時間（既定 24 時間。ライブを作るホストが 0〜7 日で選べる）が過ぎると、自動で消えます。結果を残したいときは、猶予の間にホストのページから書き出してください。

消えた後も、サーバーを置いている Cloudflare の仕組みの中に、最大 30 日分の控えが残ります。控えに入っているのは、上に書いたライブの中身だけで、IP アドレスなど、もともと保存していないものは入っていません。この控えから戻すには、私たちがそのためのプログラムを作って動かす必要があり、私たちはそれをしません。30 日を過ぎると、控えもなくなります。気になる場合は、ライブを付けずに書き出すか、自分で用意したライブのサーバーを教材に指定してください。

IP アドレス、ブラウザの情報、アクセスの記録は保存しません（リクエストの記録も切ってあります）。ライブを作るときだけ、作りすぎを防ぐために IP アドレスを使いますが、保存はしません（Cloudflare の確認の仕組み Turnstile と、回数の上限に使います）。教材に別のライブのサーバーが書いてあるときは、そのサーバーの決まりに従います。
