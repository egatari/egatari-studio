### Changed
- Embedded fonts are subset to the characters the lesson uses (#178): each `@fontsource` chunk the lesson needs is cut down with harfbuzz (wasm, `harfbuzzjs` 1.6.4) and re-encoded as woff2 (`wawoff2` 2.0.1), with `unicode-range` set to exactly the characters the subset font maps. This applies to `build`, `--portable`, `--play-only`, the bundled examples and the editor's save and export (the editor loads the subsetter, `font-subset.js`, on the first export; its fonts are byte-identical to the command line). The output is byte-stable across runs and operating systems. The rashomon example goes from 12.2 MB to 2.4 MB. Fonts with a Reserved Font Name (Source Sans 3, Source Serif 4, Source Code Pro) are embedded unchanged. `EGATARI_FONT_SUBSET=0` turns it off.
- Editor, tier A saves: new characters in the script or the book get a font supplement in every embedded font (BIZ UDPMincho and the chosen Japanese fonts too, not only BIZ UDPGothic and Source Sans 3), cut down to those characters. Without the font files (the offline `editor.html` has no Mincho) the editor saves anyway and names the characters that will show in the device's font, instead of refusing.

### Added
- The quality checker warns `fontNotCovered` when visible characters are in no embedded font (they show in the device's font); `node tools/font-coverage.mjs <built.html>` lists them.
