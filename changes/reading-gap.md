### Added

- The quality check warns when a term has a reading `{x|y}` somewhere in the script but appears elsewhere without one (`readingGap`, rule R-reading, in the command line and the editor). A reading applies only where it is written and the player does not use the reading dictionary, so a bare repeat can be misread (in rashomon, 下人 was read as したひと). The message offers both fixes: add the reading here, or, if the term reads correctly without one, remove it where it was given. The instructions for the AI now say to give a reading only to a term misread without one, and then every time it comes back (backlog #203)
