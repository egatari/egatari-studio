### Added

- The quality check warns when a term has a reading `{x|y}` somewhere in the script but appears elsewhere without one (`readingGap`, rule R-reading, in the command line and the editor). A reading applies only where it is written and the player does not use the reading dictionary, so a bare repeat can be misread (in rashomon, 下人 was read as したひと). The instructions for the AI now say to give the reading every time a term comes back (backlog #203)
