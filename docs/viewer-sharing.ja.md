# iPhone・iPad で教材を開く（Egatari Viewer）

[English](viewer-sharing.md) | 日本語

iPhone・iPad では、Egatari ファイル（.ega.html）を「ファイル」App やファイルのプレビューで開いても、教材は動きません（iOS はそこで HTML をスクリプトを動かさずに表示するため）。そのときは **Egatari Viewer**（`https://viewer.egatari.org/`。ホーム画面での名前は **Ega Viewer**）で開きます。ファイルは端末の中で読まれ、どこにも送られません。

Slack や Teams のように HTML を自分で開くアプリでは、Viewer なしでそのまま再生できます（アプリの中のブラウザが教材のスクリプトを動かすため）。

## 配る人：再生専用をエクスポートして渡す

1. Egatari Studio で教材を開き、**「ファイル ▾」→「エクスポート ▸」→「参加者用（再生専用）…」** を選ぶ。
2. 窓の **「エクスポート…」** を押し、保存する（ファイル名は `○○.play.ega.html`）。再生専用のファイルは再生だけができ、編集はできません。直すための元のファイルは手元に残します。
3. いつもの方法で渡す（たとえば Classroom・Google ドライブ・メール）。iPhone・iPad で受け取る人には、次の 1 行を添えます：

   > iPhone・iPad では、ファイルを「"ファイル"に保存」してから、**Ega Viewer** の「ファイルを開く」で開いてください。

## 受け取る人：iPhone・iPad の Ega Viewer で開く

1. はじめの 1 回だけ：`viewer.egatari.org` を開き、ホーム画面に追加する。Safari では「共有」（□に↑の形）→「表示を増やす」→「ホーム画面に追加」→「追加」。Chrome では「共有」→「表示を増やす」→「ホーム画面に追加」（「Web アプリとして開く」はオンのまま）→「追加」。Viewer の最初の画面にも同じ案内が出ます。ホーム画面に「え」のアイコンの **Ega Viewer** ができ、次からはネットワークがなくても開けます。
2. ファイルを端末に置く：受け取ったアプリ（メール・Google ドライブ・学校のアプリなど）でファイルの共有のメニューを開き、「"ファイル"に保存」。Google ドライブにあるファイルは、そのままでもかまいません（次の 3）。Ega Viewer は共有の一覧には出ないので、そこから直接は開けません。
3. **Ega Viewer** を開き、**「ファイルを開く」** →「ファイルを選択」で、保存したファイルを選ぶ。Chrome から追加した Ega Viewer では「Google ドライブ」も出るので、そこからも選べます。上の帯に教材の題名と「Egatari ファイル（再生専用）」が出て、再生が始まります。スライドを押すと下に操作の帯が出ます。「→」（次へ）で進み、「字幕」で字幕が出ます。
   - Safari から追加したときでも、「ファイル」App の場所に Google ドライブを入れてあれば（「ブラウズ」→「編集」でオン）、「ファイルを選択」の中から選べるはずです（未確認）。
4. 次からは、最初の画面の「最近のファイル」から開けます（何人かで使う端末では「共有の端末」をオンにすると、残しません）。

ライブ（質問・投票）付きの教材は、開くと先に「参加する」と「参加しないで見る」が出ます。ライブに参加するときだけネットワークを使います。

うまくいかないとき：画面に出た文のとおりにしてください（たとえば「Egatari ファイルではありません。…」なら、`.ega.html` のファイルを選び直す）。ファイルのプレビューや「ファイル」App で開いても動かないのは正しい動きです。

くわしくは [Egatari Viewer](viewer.ja.md) と [教材を配る](distributing.ja.md)。
