# Reference voices for the lab page

`alice.wav` (48 kHz) and `bob.wav` (16 kHz) are the default synthetic voices of this project
(alice: Qwen3-TTS VoiceDesign, Apache-2.0; bob: Irodori-TTS, MIT). No real person's voice was
recorded or cloned. They are copies of `tts/voices/alice.wav` and `tts/voices/bob.wav` from the
`windows` branch, placed here so the static lab page (and its GitHub Pages copy) can fetch them.
Label audio made with them as AI-generated.
