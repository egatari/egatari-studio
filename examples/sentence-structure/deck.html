英語（高校 1 年）・文の組み立て

英文の構造

動詞を見つけて、記号で区切る

文を組み立てる 5 つの記号

文の骨組みは S・V・O・C、M は飾り

まず動詞を見つける

[S My brother] [V plays] [O tennis] [M every Sunday]. = 兄は毎週日曜日に、テニスをする。

M を外しても文になる：My brother plays tennis.

動詞の前が S、後ろが O、残りは M

C は、O がどんなかを言う

[S The news] [V made] [O her] [C happy]. = その知らせは、彼女を幸せにした。

O と C だけ取り出すと：She is happy.（彼女は幸せだ）

O と C の間には「O は C だ」が成り立つ

節が、前の名詞を飾る

[S The cake {形^ [O that] [S she] [V made]}] [V is] [C good]. = 彼女が作ったケーキは、おいしい。

括弧を外すと：The cake is good.

括弧でくくると、文の本当の動詞が見える

読むときの順番

長い文も、動詞から区切れば骨組みが見える
