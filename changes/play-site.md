### Added

- Egatari Play (`play/`, `tools/build-play.mjs` → `_play/`): a web app page that opens an Egatari file on the device and plays it, for iPhone and iPad (no local HTML from the Files app), Android `content://` trouble and chat previews that fail. The lesson runs in a `sandbox="allow-scripts"` srcdoc frame behind Studio's trusted preview prefix; recent files stay on the device (OPFS, IndexedDB fallback) and can be deleted; Android `share_target`; a versioned service worker that caches only the page's own files. Not deployed yet (docs/play.md)
- Egatari Play acts for the lesson in Live (format spec live §2A): the page shows Join in its own chrome and holds the WebSocket, learns the step from the lesson's position events and relays nothing into the lesson; endpoints the page does not allow get the join link. Links the lesson asks to open go through `kit/core/link-policy.mjs` in the page's own box

### Security

- Egatari Play refuses to run in a frame (`frame-ancestors 'none'`, `X-Frame-Options: DENY` in `_headers`, and a script check). Self-hosters need a host that sends headers (docs/play.md "Self-hosting")
- Egatari Play follows format spec 3e4b4a6: the lesson asks for links with the §9.4 event `{egatari: "openLink", href, text}` (only on the viewer's activation, text up to 200 characters; the page applies §11 and opens nothing without a tap in its own box), and a host agreed to before gets a plain 「開く」 with its name (§11 (f)). A 「共有の端末」 (Shared device) switch keeps no recent files and deletes the kept ones
- Egatari Play follows format spec c002455: an `openLink` with `download: true` is refused with the host and 「この教材からはファイルを保存できません」. The Live pane is shown from the start beside or below the lesson, never over it, and nothing resizes or covers the lesson's frame while it plays (the update notice waits), so a tap meant for the page is never handed to the sandboxed frame
- Egatari Play's Live layout: a lesson with Live starts on a Join screen (or 「参加しないで見る」, which makes no request) before its frame is placed, and the layout is chosen once from the activities and the screen (a bar, a pane below or beside the stage, or the side slack in phone landscape; on 16:9 phones an indicator over the frame's top edge, or a 28 px strip, behind one constant), laid out again only on rotation. `tools/play-tap-measure.mjs` counts taps lost to the lesson's frame
- Egatari Play: each poll choice's whole row is the tap target (44 px tall where it fits, at least 24 × 24 px in the strip); the overlay is the default on 16:9 phones in landscape; the UI says ホスト and ライブ instead of 先生 and 部屋 (host, Live instead of teacher, room)
