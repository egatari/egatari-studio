# テーマ `default`

[English](README.md)

同梱の既定のテーマ。版は `theme.json` にあり、前の版は `vendor/themes/default/<版>/` に残して `themes.lock.json` に載せる（[リファレンス](../../docs/reference.ja.md#テーマ)「テーマの版」）。組み立てが読むのは `theme.json` と `tokens.css` だけで、このファイルはテーマの hash に入らない。

## この色にした理由（1.1.0）

| token | 値 | 白地 | 役割 |
|---|---|---|---|
| `--emph` | `#BE3012` | 5.80:1（WCAG AA） | 結論・問題・目標 |
| `--muted` | `#5C5853` | 7.06:1（WCAG AAA の水準） | 既知の結果・比較の相手・図の説明・引用 |
| `--fg` | `#222222` | 15.91:1 | 本文（墨） |

- **`--emph` `#BE3012`。** カラーユニバーサルデザイン（CUD）が P 型・D 型の色覚の人のために勧める、黄み（橙）寄りの赤を、文字に使える濃さにしたもの。白地 5.80:1 で WCAG AA を満たす。1 型色覚の模擬で墨との CIEDE2000 の色差は 22.5 から 26.0 に上がり、結論の行が本文と同じ黒に見えにくい。前の臙脂 `#C50516`（1.0.0、`oklch(0.52 0.21 27)`）は青みに寄っていて、CUD が避けるよう勧める側だった。意図して選んだ色ではなかった。
- **`--muted` `#5C5853`。** 白地 7.06:1（WCAG AAA の水準）。教室の光で黒が浮くプロジェクターでも、小さい字（`.cite`・`.figcap`）でも読める。引き換えに墨との色差は小さくなる（CIEDE2000 25.6 → 18.2）。灰の字は色だけでなく役割と位置（図の説明・引用・比べる相手の結果）でも墨と分かれるので、これでよいとした。
- これらの token を書かずに `default` を継ぐテーマは、そのまま受け継ぐ。`kokugo` は自分の赤（`--emph-hue: 38`）のまま、新しい灰を継ぐ。

## 結論の行（1.2.0）

@totasuko-lab さんの plain テーマの提案から（1.1.0 は色だけを取り入れた）。結論の行は、色だけに頼らないように（WCAG 1.4.1）4 つの手がかりで示す：左の `--emph` の 5px の縦線、決まった位置（上端 571px・高さ 72px。前と同じ）、太字、淡い地 `--concl-bg`。字は枠の中央でなく、縦線から左揃えにする。縦組み（`layout-tate`）の結論の列は今までの枠のまま。

| `--concl-bg` の候補 | `--emph` の字 | `--fg` の字 | 白地との差 | `--emph` の字（白飛び 15%） |
|---|---|---|---|---|
| `#FFFFFF`（1.1.0。透明） | 5.80:1 | 15.91:1 | 1.00（なし） | 3.37:1 |
| **`#F5F5F5`**（採用） | **5.32:1** | **14.59:1** | 1.09、ΔE00 2.0 | 3.13:1 |
| `#F6F3EF`（提案の生成り） | 5.24:1 | 14.38:1 | 1.11、ΔE00 3.2（白黒では 2.3） | 3.10:1 |

- **`--concl-bg` `#F5F5F5`。** 無彩の灰は色相を持たないので、どの型の色覚でも白黒の印刷でも同じに見え、行の帯がどこでも同じ程度に分かる。手がかりは縦線と太字が担うので、地はかろうじて見えれば足りる。行が分かる地のうちで、字のコントラストを最も落とさない（`--emph` 5.32:1。大きさによらず AA）。生成り `#F6F3EF` は色のある画面では少し目立つが、白黒では色の見た目ほど分かれず、コントラストも余計に落とす。
- `default` を継ぐテーマは形を受け継ぐ。`kokugo` は自分の赤の縦線と灰の地、`business` は自分の淡い橙の `--concl-bg` のまま。

## 光：`--lit`（1.3.0）

`--lit` は光と、光が照らすもの（太陽・灯り・月の明るい側。format spec §8.4）の役割。塗りの色で、字の色には使わず、いつも `--fg` か `--muted` の輪郭線と一緒に描く。

| 変数 | 値 | 白地 | 色覚の模擬での `--emph` との差（ΔE*ab 3 色型/1 型/2 型/3 型、ΔE00） |
|---|---|---|---|
| `--lit` | `#F5B800` | 1.79:1 | 65/55/42/54、44.4/39.8/28.3/30.7 |

- **`--lit` `#F5B800`。** 日の光や灯りの色として思い浮かぶ、少し山吹寄りの暖かい黄。白地では淡い（1.79:1）ので、形は輪郭線が見せる。WCAG 1.4.11 の 3:1 は塗りではなく輪郭線が満たす。模擬した 4 つの色覚の型のどれでも、`--emph` との差が `--emph` と `--term` と同じ線を越える（`node tools/test-themes.mjs`）ので、太陽と結論を取り違えない。
- 同梱のテーマはそれぞれ自分の `--lit` を持つ（配色に合う暖かい黄。`sumi` と `business` は橙の `--emph` から離した）。`default` を継ぐテーマで宣言しないものは `#F5B800` を受け継ぐ。

## 物の色：`--obj-*`（1.4.0）

`--obj-white` … `--obj-gray` は 11 の基本色名で、色そのものが内容である色に使う：袋の中の赤い玉、青のリトマス紙、青信号（format spec §8.4）。塗りの色で、物の上か横に色の名前か頭文字（「赤」、"R"）を添え、色だけで伝えない（たとえば赤と緑は多くの人に似て見える）。白・黒と地に近い色には `--fg` か `--muted` の輪郭線も付ける。図の系列は `--series-*`、意味は上の役割を使う。

| 変数 | 値 | OKLCH L / C / h | 白地 |
|---|---|---|---|
| `--obj-white` | `#FFFFFF` | 1.000 / 0.000 / – | 1.00:1 |
| `--obj-black` | `#222222` | 0.252 / 0.000 / – | 15.91:1 |
| `--obj-red` | `#E0242B` | 0.584 / 0.219 / 26.1 | 4.71:1 |
| `--obj-green` | `#2E9E44` | 0.617 / 0.163 / 146.5 | 3.45:1 |
| `--obj-yellow` | `#F5D90A` | 0.882 / 0.182 / 99.8 | 1.42:1 |
| `--obj-blue` | `#1E6FD9` | 0.555 / 0.179 / 257.4 | 4.85:1 |
| `--obj-brown` | `#8B5A2B` | 0.512 / 0.090 / 62.2 | 5.84:1 |
| `--obj-purple` | `#8E44AD` | 0.526 / 0.170 / 314.7 | 5.87:1 |
| `--obj-pink` | `#F27BB0` | 0.733 / 0.156 / 353.6 | 2.55:1 |
| `--obj-orange` | `#F28C1A` | 0.734 / 0.165 / 60.4 | 2.46:1 |
| `--obj-gray` | `#8C8C8C` | 0.640 / 0.000 / – | 3.36:1 |

- **名前どおりに見える。** 色相は OKLCH でそれぞれの窓に入る（red 15–45°、orange 50–80°、yellow 85–115°、green 125–165°、blue 235–275°、purple 285–335°、pink 340–15°。窓はその名前の CSS の色の色相を含み、互いに重ならない）。brown は orange と同じ色相で、暗く鮮やかさが低いことで分かれる（明るさ 0.35–0.60、鮮やかさ 0.04–0.12）。white・black・gray は鮮やかさ 0.02 以下（`node tools/test-themes.mjs`）。
- **隣どうしが分かれる。** 隣り合う色の名前（red–orange、orange–yellow、yellow–green、green–blue、blue–purple、purple–pink、pink–red、brown–orange、brown–red、gray–white、gray–black）は 3 色型で ΔE00 20 以上離す。`--emph` と `--term` と同じ線で、並べなくても 1 つずつ見て投影で名前を言い分けられる差。ここで最も近い組は brown–red（23.7）。名前か頭文字をいつも添えるので、色覚の模擬は求めない。
- **黄は `--lit` と別。** `--obj-yellow` はレモン寄りの黄（h 99.8）で、山吹寄りの `--lit`（h 84.4）から離した（ΔE00 11.1）。役割が違う：`--lit` は光と光が照らすもの、`--obj-yellow` は黄色い物で、どのみち名前を添える。2 つのあいだに線は決めない。
- 地とのコントラストは求めない（名前と輪郭線を添える塗り）。白地では 1.4〜15.9:1。`sumi`・`kokugo`・`tokiwa`・`murasaki`・`business` は同じ値なので、どのテーマでも赤い玉は同じ赤。`kogecha` は落ち着いた配色に合わせて鮮やかさを少し抑え、`asagi` は小学校向けに少し明るい。同梱のテーマはどれも 11 色を自分の `tokens.css` で宣言する。`default` を継ぐテーマで宣言しないものはこの値を受け継ぐ。
