Scaled dot-product attention

  • Each query is compared with every key: $QK^T$
  • The scores are scaled by $\sqrt{d_k}$ before the softmax
  • The output is a weighted sum of the values
Attention is a soft lookup table

Multi-head attention

  • Run $h = 8$ attention heads in parallel
  • Each head projects to $d_k = d_{model}/h$ dimensions
  • Heads look at different relations
Several heads, several views
