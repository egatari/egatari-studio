### Added

- Ink notes in edit mode (#70): `m` or the pen key `d` (or the "Ink note (m)" button in the editor's edit-mode bar, or the slide controls' pen button, which reads "Ink note" while editing and is the only tool button left there) turns the pointer into a comment pen; `d` typed into a text field stays text and the presenter view still cannot choose tools while editing; drawing a circle or an arrow on the slide opens the same note box as Alt+click, and the mark is kept in `comments.json` as `stroke` (`[[x, y], …]` in slide coordinates, at most 500 points; `pin` is its centroid; contract §12). The editor's overlay and `npm run comment-shots` draw it in the pin colour, the crop covers it, and the mode indicator reads "Editing: ink note".
