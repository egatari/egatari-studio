### Added
- Editor: load custom themes from a ZIP file in every browser, including Safari, Firefox and the iPad. **Load theme…** (theme list, theme notice, **My themes…**) opens a small dialog with **Choose ZIP file…** and, where the browser can choose folders, **Choose folder…**. Themes are found up to 5 levels deep (a GitHub “Download ZIP” works), all themes in the file are loaded so `extends` within it resolves, and the file is read as untrusted (size, entry and per-file limits; `..`, absolute paths, symbolic links and bad theme names refuse it). The themes are saved in the browser as “My themes”, can be deleted one by one in **My themes…**, and with a theme folder the theme chosen or loaded last wins.
